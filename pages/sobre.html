Sobre

O projeto

Este é um jogo da velha feito em JavaScript com o tema Batman vs Superman. O Batman e o Superman se enfrentam no tabuleiro, e o vencedor tem suas três peças destacadas em amarelo.

Dois jogadores se revezam no mesmo tabuleiro, e o jogo reinicia sozinho alguns segundos depois do fim de cada partida.

Tecnologias
  • HTML e CSS
  • JavaScript puro, sem bibliotecas, para a lógica do jogo
  • Bootstrap 5 e Bootstrap Icons para o layout, o menu e o slide show
